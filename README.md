# EDA-Derechos-de-movilidad-de-las-mujeres
El objetivo de este proyecto es analizar y visualizar un dataset relacionado con los derechos de movilidad de las mujeres a nivel global.   El análisis se centra en entender cómo las leyes, las políticas públicas y su implementación real influyen en la igualdad de género, así como el papel que juega el nivel económico de los países.
